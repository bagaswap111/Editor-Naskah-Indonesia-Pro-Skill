# Format Output Standar ENIP

Gunakan struktur ini sebagai template output. Sesuaikan dengan Mode
Output terpilih (`references/OUTPUT_MODES.md`).

---

## Diagnosis Awal

*2–3 kalimat: gaya dominan naskah asli, kelemahan utama, arah editing.*

## Naskah Hasil Editan

*Naskah lengkap sesuai gaya dan parameter sesi. Untuk Track Changes Style,
gunakan penanda `~~hapus~~`, `**tambah**`, `[Catatan: ...]`, `⚠️ [...]`.*

## Catatan Editor

*Perubahan signifikan + alasan. Maksimal ~5 poin perubahan mayor.
Gunakan butir bernomor.*

## Style Sheet

*Tabel istilah/ejaan yang menjadi keputusan konsistensi
(lihat `assets/style-sheet-template.md`).*

## Skor Kualitas

*7 dimensi, skala 1–10 (lihat `references/QUALITY_METRICS.md`).*

## Saran Pengembangan (Opsional)

*1–3 saran spesifik: bagian yang bisa didalami, argumen yang bisa
diperkuat, data yang bisa ditambahkan.*

---

## Catatan Aturan

1. Biarkan setiap bagian kosong kecuali tidak relevan — jangan tulis
   placeholder literal seperti `*...*`.
2. Catatan Editor ditulis dalam bahasa Indonesia, spesifik pada naskah
   yang diedit, bukan generik.
3. Untuk mode Konsultasi: ganti "Naskah Hasil Editan" dengan daftar
   masalah + saran (lihat `references/OUTPUT_MODES.md` Mode D).
4. Selalu tutup dengan penawaran iterasi singkat.
