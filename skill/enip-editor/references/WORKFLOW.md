# Alur Kerja Editing — Referensi Detail ENIP

Bacalah file ini saat menjalankan Alur Kerja 7 Tahap, terutama untuk
struktur paragraf, transisi, kedalaman penjelasan, dan penanganan kasus
khusus.

## A. Struktur Paragraf Ideal (TEEL+)

Tiap paragraf eksplanatori harus berkembang organik, bukan tempelan kalimat:

| Huruf | Elemen | Fungsi |
|---|---|---|
| T | Topic Sentence | Ide utama paragraf |
| E | Explanation | Penjelasan/elaborasi |
| E | Evidence/Example | Bukti, data, atau contoh konkret |
| L | Link | Kalimat penghubung ke paragraf berikutnya |
| A | Analogy/Analisis | Opsional: analogi atau analisis mendalam |

## B. Teknik Transisi Antarparagraf

| Jenis | Contoh |
|---|---|
| Aditif | Di samping itu, Lebih dari sekadar..., Tidak hanya... tetapi juga... |
| Kontrastif | Sebaliknya, Berbeda dengan pandangan tersebut, Kendati demikian... |
| Kausal | Akibatnya, Hal ini berdampak pada..., Implikasinya adalah... |
| Sekuensial | Langkah selanjutnya, Setelah fase ini, Pada tahap berikutnya... |
| Ilustratif | Sebagai ilustrasi, Untuk memperjelas, Ambil contoh... |
| Konsesif | Meskipun benar bahwa..., Terlepas dari..., Walau begitu... |
| Konklusif | Dengan demikian, Secara keseluruhan, Dapat disimpulkan bahwa... |

Variasikan jenis transisi; jangan ulang satu jenis secara beruntun.

## C. Perkembangan Ide (Progression)

Setiap paragraf harus memajukan argumen, bukan mengulang. Pola yang bisa
digunakan:

- **Umum → Khusus (deduktif)**: pernyataan luas → bukti spesifik.
- **Khusus → Umum (induktif)**: data/kasus → generalisasi.
- **Kronologis**: urutan waktu.
- **Komparatif**: perbandingan dua konsep.
- **Problem-Solution**: identifikasi masalah → analisis → solusi.

## D. Model Kedalaman Berlapis (teks eksplanatori)

Lapis 1: APA (definisi/pernyataan)
→ Lapis 2: MENGAPA (alasan/mekanisme)
→ Lapis 3: BAGAIMANA (proses/implementasi)
→ Lapis 4: CONTOH/ANALOGI (konkretisasi)
→ Lapis 5: IMPLIKASI/NUANSA (so what? batasan? pengecualian?)

**Aturan**: setiap klaim penting minimal mencapai Lapis 3. Klaim
kontroversial atau kompleks harus mencapai Lapis 5.

## E. Teknik Analogi & Contoh

| Jenis | Fungsi | Contoh |
|---|---|---|
| Analogi struktural | Menjelaskan sistem kompleks | "Otak bekerja seperti kota: neuron adalah jalan raya, sinapsis adalah persimpangan." |
| Analogi fungsional | Menjelaskan proses | "Inflasi seperti balon yang diisi udara terus-menerus—akhirnya meletus." |
| Contoh konkret | Mengabstraksi menjadi nyata | Daripada "banyak orang terdampak", tulis: "Di Desa X, 340 keluarga kehilangan akses air bersih selama 3 bulan." |
| Counter-example | Memperjelas batasan | "Ini bukan berarti semua regulasi buruk. Regulasi lalu lintas, misalnya, menyelamatkan nyawa." |
| Analogi budaya lokal | Relevansi kontekstual | "Gotong royong dalam proyek ini mirip konsep 'sambatan' di Jawa—semua berkontribusi sesuai kapasitas." |

**Aturan validasi analogi**:
1. Analogi harus menerangi, bukan mengaburkan.
2. Akui keterbatasan analogi jika perlu: "Tentu, analogi ini tidak sempurna
   karena..."
3. Hindari analogi klise kecuali diberi twist baru.

## F. Rincian 7 Tahap

1. **Intake & Diagnosis** — baca naskah utuh. Identifikasi: gaya dominan
   yang sudah ada, target pembaca tersirat, kelemahan utama. Sampaikan
   Diagnosis Awal 3–5 kalimat ringkas.
2. **Editing Substantif** — evaluasi struktur makro: urutan bab/bagian,
   gap penjelasan, argumen melompat, bagian terlalu tipis/tebal. Sarankan
   reorganisasi bila perlu (beri pilihan, jangan paksa).
3. **Editing Struktural** — per paragraf: TEEL+, transisi, buang redundansi,
   pastikan perkembangan ide konsisten.
4. **Editing Kalimat** — perbaiki kalimat rancu/ambigu/panjang, variasikan
   ritme, paralelisme, terapkan gaya (lihat `STYLE_GUIDE.md`).
5. **Proofreading** — koreksi PUEBI (lihat `PUEBI.md`), buat Style Sheet
   internal, verifikasi angka, singkatan, kata serapan, konsistensi istilah.
6. **Enhancement** — sisipkan analogi tepat, perdalam penjelasan dangkal,
   tambah transisi hilang, perkuat argumen.
7. **Output & Catatan Editor** — susun output sesuai mode
   (`OUTPUT_MODES.md`) dan template (`assets/output-template.md`).

## G. Penanganan Kasus Khusus

### G.1 Dialog dalam Fiksi
PUEBI berlaku untuk narasi, tetapi dialog boleh memakai bahasa non-baku
sesuai karakter. Tandai: "Dialog ini menggunakan register informal —
konsisten dengan karakterisasi. Tidak diedit."

### G.2 Istilah Asing
- Pertama kali muncul: *italic* + terjemahan dalam kurung. Contoh:
  *cognitive dissonance* (disonansi kognitif).
- Setelahnya: gunakan istilah Indonesia yang sudah diserap.

### G.3 Catatan Kaki & Catatan Akhir
- Buku populer: catatan kaki untuk referensi atau anekdot tambahan.
- Akademis: bodynote atau endnote sesuai format terpilih.

### G.4 Penanganan Sensitivitas
- Tandai bahasa yang berpotensi bias (gender, etnis, disabilitas).
- Sarankan alternatif inklusif tanpa mengubah makna. Contoh:
  "ketua panitia dan istrinya" → "ketua panitia dan pasangannya"
  (jika konteks memungkinkan).
