# Akurasi Fakta & Referensi — Protokol Verifikasi ENIP

Bacalah file ini saat Tahap 2 (Editing Substantif), Tahap 6 (Enhancement),
dan saat menulis Catatan Editor.

## A. Protokol Verifikasi

| Tingkat Klaim | Tindakan ENIP |
|---|---|
| Fakta umum (common knowledge) | Tidak perlu rujukan. Contoh: "Indonesia merdeka pada 1945." |
| Data statistik spesifik | Tandai `[Sumber?]` jika tidak ada referensi. Contoh: "78% siswa..." |
| Klaim kausalitas | Tandai `[Korelasi ≠ Kausalitas?]` jika logika belum kuat. |
| Kutipan langsung | Wajib verbatim + sumber. Tandai `[Verifikasi Kutipan]` jika ragu. |
| Teori/kerangka konseptual | Sebutkan nama pencetus + tahun. `[Rujukan lengkap diperlukan]` |
| Klaim kontroversial | Wajib ≥2 sumber. Tandai `[Klaim Kontroversial – Perlu Dukungan]` |

## B. Format Referensi

| Format | Konteks |
|---|---|
| APA 7th Edition | Default untuk sosial-humaniora |
| Chicago/Turabian | Sejarah, sastra |
| IEEE | Teknik, komputer |
| Vancouver | Kedokteran, kesehatan |
| Catatan kaki | Buku non-fiksi populer |

Gunakan format sesuai parameter sesi. Untuk buku populer tanpa format
referensi ketat, gunakan catatan kaki.

## C. Penanganan Ketidakpastian

Jika ENIP tidak dapat memverifikasi:

> ⚠️ "Pernyataan ini belum dapat diverifikasi dari sumber yang tersedia.
> Disarankan penulis merujuk pada [saran sumber] atau menghapus klaim ini
> jika tidak esensial."

Aturan keras:
- Jangan mengarang referensi.
- Jangan mengarang angka, nama peneliti, atau tahun.
- Bedakan "saya ingat ini benar" dengan "ini terverifikasi". Jika hanya
  ingatan, tandai `[Verifikasi]`.

## D. Integrasi dengan Workflow

- Tahap 2: tandai klaim bermasalah selama membaca struktur makro.
- Tahap 6: untuk klaim yang perlu penguatan, sarankan jenis bukti yang
  sesuai (statistik, studi kasus, kutipan pakar) tanpa mengarang datanya.
- Catatan Editor: laporkan semua klaim yang ditandai sebagai daftar
  "Perlu Verifikasi Penulis" agar penulis dapat menindaklanjuti.
