# Panduan Gaya Bahasa (Style Engine)

Bacalah file ini saat menentukan atau menerapkan gaya bahasa pada Tahap 4
(Editing Kalimat) dan Tahap 6 (Enhancement).

## A. Gaya Dasar

### 🎓 A. Akademis Formal
- **Karakteristik**: Objektif, impersonal (hindari *saya/kita* kecuali
  konvensi bidang), terminologi teknis presisi, kalimat kompleks
  terstruktur, hedging terukur ("cenderung", "dapat diinterpretasikan").
- **Struktur kalimat**: dominan kalimat pasif dan nominalisasi.
  "Telah dilakukan analisis terhadap..."
- **Transisi khas**: Dengan demikian, Berdasarkan uraian di atas,
  Sebagaimana dikemukakan oleh..., Temuan ini mengindikasikan bahwa...
- **Catatan editor**: wajib sertakan [Rujukan?] untuk setiap klaim empiris.

### 📰 B. Jurnalistik Informatif
- **Karakteristik**: piramida terbalik (inti dulu, detail menyusul),
  kalimat pendek (15–25 kata), aktif, konkret, angka dan nama spesifik.
- **Struktur**: Lead → Konteks → Detail → Kutipan → Penutup.
- **Transisi khas**: Sementara itu, Di sisi lain, Menurut data...,
  Lebih lanjut...
- **Catatan editor**: hindari adjektiva subjektif tanpa bukti
  ("sangat mengejutkan" → tunjukkan datanya).

### 🌸 C. Naratif Sastrawi
- **Karakteristik**: majas (metafora, simile, personifikasi, hiperbola),
  variasi ritme kalimat (pendek untuk ketegangan, panjang untuk
  kontemplasi), sensory details, show don't tell.
- **Struktur**: bisa non-linear (flashback, in medias res, frame story).
- **Transisi khas**: lebih implisit, melalui lompatan citra atau emosi.
- **Catatan editor**: PUEBI tetap berlaku, tetapi kelonggaran diberikan
  untuk licentia poetica. Tandai ambiguitas yang tidak disengaja.

### 💡 D. Populer-Edukatif
- **Karakteristik**: conversational, analogi sehari-hari, pertanyaan
  retoris, humor ringan diperbolehkan, menjelaskan konsep kompleks dengan
  bahasa sederhana.
- **Struktur**: Hook → Masalah → Penjelasan (dengan analogi) → Aplikasi →
  Ringkasan.
- **Transisi khas**: Bayangkan begini..., Nah, di sinilah menariknya...,
  Kalau diibaratkan..., Pertanyaannya sekarang...
- **Catatan editor**: pastikan analogi tidak menyesatkan. Cek akurasi
  simplifikasi.

### ⚖️ E. Persuasif-Argumentatif
- **Karakteristik**: tesis jelas, argumen berlapis (klaim → bukti →
  warrant → qualifier), antisipasi kontra-argumen, call to action.
- **Struktur**: Tesis → Argumen 1 → Argumen 2 → Kontra-argumen + Rebuttal →
  Kesimpulan.
- **Transisi khas**: Meskipun demikian, Tidak dapat dimungkiri bahwa...,
  Namun, bukti menunjukkan..., Oleh karena itu, sudah semestinya...

## B. Gaya Campuran (Hybrid Mode)

Pengguna dapat menggabungkan 2–3 gaya. Prioritas: Primer 60% → Sekunder
30% → Tersier 10%.

| Kombinasi | Hasil | Cocok untuk |
|---|---|---|
| Akademis + Populer | Penjelasan ilmiah, bahasa mudah dicerna | Buku sains populer, textbook mahasiswa baru |
| Jurnalistik + Sastrawi | Feature writing, narasi berbasis fakta | Longform journalism, esai naratif |
| Persuasif + Akademis | Argumen berbasis riset dengan daya dorong | Policy brief, opini ilmiah |
| Sastrawi + Populer | Storytelling ringan dengan kedalaman emosi | Memoar, self-help naratif |
| Akademis + Jurnalistik + Populer | Penjelasan kompleks, terstruktur, tetap engaging | Buku teks populer (ala Freakonomics) |

## C. Parameter Mikro Gaya (Fine-Tuning)

| Parameter | Rentang | Default |
|---|---|---|
| Panjang kalimat rata-rata | Pendek (10–15) / Sedang (15–25) / Panjang (25–40 kata) | Sedang |
| Tingkat formalitas | 1–10 | 5 |
| Densitas terminologi teknis | Rendah / Sedang / Tinggi | Sedang |
| Frekuensi analogi | Jarang / Sedang / Sering | Sedang |
| Kalimat tanya retoris | Tidak / Kadang / Sering | Kadang |
| Toleransi licentia poetica | Ketat / Moderat / Longgar | Moderat |
| Perspektif naratif | Orang pertama / Kedua / Ketiga / Omniscient | Sesuai naskah |

## D. Prosedur Penerapan Gaya

1. Pastikan parameter sesi lengkap (gaya, formalitas, panjang kalimat, dll.).
2. Baca naskah asli dan identifikasi register saat ini (lihat
   `PUEBI.md` bagian G).
3. Terapkan gaya secara konsisten di seluruh naskah — jangan setengah-setengah.
4. Saat hybrid: biarkan gaya primer mendominasi keputusan diksi dan
   struktur; gaya sekunder memberi warna transisi dan contoh; gaya tersier
   hanya sentuhan halus.
5. Catat keputusan gaya di Style Sheet (`assets/style-sheet-template.md`).
