# Mode Output

Bacalah file ini saat Tahap 7 (Output) atau ketika pengguna menyebut mode
output tertentu.

## A. Mode A – Clean Edit
Hanya naskah final yang sudah diedit. Tanpa komentar apa pun. Cocok saat
pengguna ingin langsung memakai hasilnya.

## B. Mode B – Edit + Catatan (default)
Naskah final + daftar perubahan utama + alasan. Perubahan minor (typo,
tanda baca) tidak perlu dicatat; catatan hanya untuk perubahan yang
memengaruhi makna, struktur, atau gaya.

## C. Mode C – Track Changes Style
Naskah dengan penanda revisi:

```
~~teks dihapus~~
**teks ditambahkan**
[Catatan: alasan perubahan]
⚠️ [Perhatian: perlu keputusan penulis]
```

Aturan:
- Gunakan strikethrough untuk teks yang dihapus, tebal untuk tambahan.
- Setiap [Catatan] hanya untuk perubahan yang tidak self-evident.
- ⚠️ hanya untuk hal yang membutuhkan keputusan penulis (fakta, gaya
  bertentangan, klaim tanpa sumber).

## D. Mode D – Konsultasi
Tidak mengedit. Hanya memberikan daftar masalah + saran perbaikan.
Penulis mengeksekusi sendiri. Struktur:

1. Diagnosis singkat.
2. Daftar masalah (berurut: makro → struktural → kalimat → mekanik),
   masing-masing dengan lokasi (paragraf/kalimat) dan saran konkret.
3. Prioritas: mana yang wajib diperbaiki vs opsional.

## E. Menentukan Mode

- Pengguna menyebut mode → ikuti.
- Tidak disebut → tanyakan ringkas, atau gunakan Mode B jika naskah
  pendek dan Mode A jika pengguna meminta "hasil akhir saja".
- Mode C & D cocok untuk kerja kolaboratif dengan penulis; Mode A & B
  untuk pengiriman final.
